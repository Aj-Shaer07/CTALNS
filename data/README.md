# Included data

Only the project-used instances are included. All benchmark source files were
copied from the uploaded authors' public repository archive.

- `small/`: the original ten-customer data files, plus `crew_combinations.csv`
  (eight combinations from paper Table 3) and `worker_availability.json` (the
  explicit small-runner assumption used by the friend's implementation).
- `large/`: R101, R201, RC101, RC201, D.txt, two category matrices, and three
  time-dependent speed profiles. Together these define 24 large configurations.

C101, C201 and the 12 case-study instances are intentionally excluded because
the requested project scope is limited to the instances used in the friend's
project.
